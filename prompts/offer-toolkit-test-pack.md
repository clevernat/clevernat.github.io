# Offer Toolkit on claude.ai: my test pack

From the AI Walkthru video. Every person and company in the test files is fictional.

## Install
1. Download offer-toolkit-fixed-zips.zip and unzip it (six skill zips inside).
2. claude.ai > Customize > Skills > Add > Upload skill. Pick all six zips. Upload.

## Test 1: should I apply?
New chat. Attach Jordan-Reyes-Resume.pdf and Cobalt-Bay-Senior-Data-Scientist.pdf. Type / and pick job-description-skill. Then:

```
Should I apply to this job? The job post and my resume are attached. Be honest about the gaps.

```

## Test 2: which offer?
New chat. Attach Offer-Cobalt-Bay-Health.pdf and Offer-Kitefin-AI.pdf. Type / and pick offer-compare-skill. Then:

```
Compare these two offers and tell me which one to take. I want to grow into machine learning work, AI exposure matters to me, and I have a mortgage, so steady cash matters too. Both want an answer by November 20.

```

## Test 3: ask for more
Same chat as test 2. Type / and pick salary-negotiation-skill. Then:

```
I'm leaning toward Cobalt Bay. Help me negotiate it. The recruiter told me the base salary band tops out at $175,000. Kitefin is my competing offer, with a $35,000 sign-on. I don't want to lose the Cobalt offer.

```
