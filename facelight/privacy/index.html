Facelight uploader: Privacy Policy

Last updated: 4 November 2026

"Facelight uploader" is a private tool used only by the owner of the Facelight Podcast YouTube channel (youtube.com/@facelightpodcast) to upload and manage that channel's own videos. It is not offered to the public.

What it accesses

With the channel owner's permission, it uses the YouTube Data API and the YouTube Analytics API to upload videos, set titles, descriptions, tags, thumbnails, subtitles, playlists and publish times, post a comment as the channel, and read the channel's own view and retention statistics.

What it stores

The sign-in token is stored only on the owner's own computer. No data from YouTube or Google is copied to any server, sold, or shared with anyone.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Through the Facelight Podcast YouTube channel: youtube.com/@facelightpodcast.
